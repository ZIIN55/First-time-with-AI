### ⚙️ ขั้นตอนการทำงาน

**1.การวางแผนและออกแบบระบบ (Planning & Flowchart Design)**
• เริ่มจากการประชุมวางโครงสร้างการทำงานผ่าน RPS Project Flowchart ครอบคลุมขั้นตอนการศึกษาวิจัย (Research), การออกแบบ (Design Phase), การเขียนโค้ด/ทำ Sound Design และกำหนดแนวทางแก้ไขปรับปรุงตาม Feedback ก่อนนำไปพัฒนาจริง

**2.การเก็บรวบรวมข้อมูลภาพ (Data Acquisition)**
• สมาชิกในทีมทำการเก็บภาพถ่ายมือจริงสำหรับท่าทาง ค้อน, กรรไกร และกระดาษ ผ่านสมาร์ทโฟนเข้าสู่ระบบ Teachable Machine  
เก็บรวบรวมข้อมูลจำนวน 840 รูปต่อคลาส จากหลากหลายมุมมองและสภาพแสงที่แตกต่างกัน เพื่อให้ AI มีข้อมูลที่ครอบคลุมมากที่สุด

**3.การฝึกสอนโมเดลและการตรวจสอบ (Training & Model Audit)**
• ดำเนินการรันโมเดลและตรวจสอบประสิทธิภาพการเรียนรู้ โดยตั้งค่า Epoch ไว้ที่ 100 และกำหนด Learning Rate ที่ 0.001 เพื่อให้ AI โฟกัสฟีเจอร์สำคัญของมือได้อย่างแม่นยำ จนกระทั่งค่า Loss และ Accuracy นิ่งพร้อมทดสอบ  

**4.การแก้ไขปัญหาและปรับแต่ง Dataset (Debugging & Background Class Addition)**
• พบปัญหา (Bug): ช่วงแรก AI มี Error Rate สูงกว่า 40% เนื่องจากสับสนสิ่งแวดล้อม/ฉากหลัง (Background Noise) และเดาสุ่มเมื่อไม่มีมือยื่นเข้ามาในกล้อง  • วิธีแก้ไข: สมาชิกทำการเพิ่มคลาสพิเศษชื่อ Background เข้าไปใน Dataset เพื่อสอนให้ AI รู้ว่าเมื่อใดไม่มีการทำท่าทางมือ ช่วยตัดปัญหา AI เดาสุ่มได้อย่างตรงจุด

**5.การทดสอบประสิทธิภาพจริงและการปล่อยใช้งาน (Final Testing & Launch)**
• ทดสอบระบบแบบ Real-time โดยแสดงท่าทางค้อน-กรรไกร-กระดาษ สลับกันอย่างรวดเร็ว AI สามารถตอบสนองได้อย่างแม่นยำและรวดเร็ว แสดงค่าความมั่นใจ (Confidence Rate) พุ่งสูงถึง 100% ในทุกท่าทาง และตัดเข้าสู่คลาส Background ทันทีเมื่อลดมือลง  
รวบรวม Source Code และลิงก์ทดสอบขึ้น GitHub เพื่อเผยแพร่ 

### 📝 สรุปผลการดำเนินงานของ Project
• ความสำเร็จของระบบ: ทีมงานสามารถสร้างและเทรน AI สำหรับจำแนกท่าทางมือในการเล่นเป่ายิ้งฉุบได้อย่างมีประสิทธิภาพและแม่นยำ  
• การแก้ปัญหาอย่างมีระบบ: สามารถแก้ปัญหา Classification Accuracy Problems (CANTs) หรือการทายมั่วจากฉากหลัง ด้วยเทคนิคการเพิ่ม Dataset คลาส Background ซึ่งทำให้โมเดลมีความเสถียรและตัดการทำงานได้อย่างถูกต้องเมื่อไม่มี Input  
• ประสิทธิภาพระดับสูง: AI ตอบสนองได้แบบ Real-time มีค่า Confidence สูงถึง 100% และพร้อมให้นำไปใช้งานหรือศึกษาต่อผ่าน GitHub
